## ⚡ Step-by-Step: How to Deploy on Vercel (Free 24/7 Hosting)

Once your code is on GitHub, deploying to **Vercel** takes under 60 seconds:

1. Visit [Vercel.com](https://vercel.com/) and click **"Sign Up"** (or **"Log In"**).
2. Choose **"Continue with GitHub"** and authenticate.
3. On your Vercel Dashboard, click **"Add New..." > "Project"**.
4. Find your `portfolio` repository from the list and click **"Import"**.
5. In the configuration screen:
   - **Framework Preset:** Leave as `Other` (Vercel automatically detects static HTML/CSS/JS).
   - **Root Directory:** Leave as `./`.
6. Click **"Deploy"**.
7. In about 15–20 seconds, your portfolio is live! You will receive a clean public URL like:
   ```
   https://pranjal-sonkiya.vercel.app
   ```
8. Every time you push an update to your GitHub repository in the future, Vercel will automatically redeploy the latest version instantly.
